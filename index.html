Proxmox Rclone Backup

Proxmox Rclone Backup is a personal-use application for securely backing up a private Proxmox VE server to Google Drive.

How it works

The application uses Rclone to encrypt backup files locally before uploading them to Google Drive. It also supports accessing and restoring backups.

Who uses this application?

This application is used exclusively by its owner. It is not offered as a public service.
