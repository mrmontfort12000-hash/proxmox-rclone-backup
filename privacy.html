Privacy Policy

Last updated: October 27, 2026

About this application

Proxmox Rclone Backup is a private, personal-use application used by its owner to store and restore encrypted Proxmox VE backups using Google Drive.

Google Drive access

The application requests Google Drive access to upload, list, download, and manage backup files in the owner's Google Drive account.

Data storage and security

Backup file contents and filenames are encrypted locally using Rclone Crypt before upload. Google Drive stores the encrypted backup files.

Data sharing

This application is not offered to other users. It does not sell Google user data or share it with advertisers or third-party analytics services. Backup files are stored in the owner's Google Drive.

Data retention and deletion

The owner controls backup retention and can delete stored backup files from Google Drive. Revoking Google account access prevents the application from accessing Google Drive.

Contact

This is a personal-use application. For privacy questions, contact the application owner through the support email provided on the Google OAuth consent screen.
